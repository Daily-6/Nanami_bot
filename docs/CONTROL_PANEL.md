# Nanami 本机控制台

双击仓库根目录的 `控制面板.vbs`。打开窗口只读取状态，不会启动服务、恢复机器人回复，或创建开机启动项、计划任务和 Windows 服务。

## 开始使用

1. 点 AstrBot 的“启动”，等待显示“运行中”。新启动的 AstrBot 中所有机器人连接默认暂停。
2. 点 NapCat 的“启动”。如果 QQ 登录已失效，点“QQ 扫码登录”，使用机器人对应的手机 QQ 扫码并确认。NapCat 进程运行不等于 QQ 已登录。
3. 用你当前的 AstrBot 网页账号和密码点“登录管理”。这一步只登录管理接口，不会启用机器人。如果启用了两步验证，同时填写验证码。
4. 在“机器人回复”里选择连接，点“启用选中机器人”。实际 QQ 回复还取决于 QQ 登录、白名单、模型与插件设置。
5. 需要语音时单独启动 GPT-SoVITS；仅使用文字功能不需要启动语音服务。“启动全部服务”会启动这三个服务，但只会为**新启动的** AstrBot 设置默认暂停；已在运行的服务保持当前状态。

当前已配置的测试群范围会显示在机器人页中。要更改白名单、人设、模型、语音参数，点“打开 AstrBot 网页”。控制台不会扩大已有的群聊白名单或开启主动发言。

## 各个开关控制什么

| 操作 | 作用 |
| --- | --- |
| AstrBot 启动/停止 | 管理网页、模型调用、插件和 QQ 消息处理的主服务 |
| NapCat 启动/停止 | 机器人 QQ 客户端与消息桥接 |
| 语音服务启动/停止 | 本机 GPT-SoVITS 合成服务，停止后释放对应进程占用 |
| 启用/暂停选中机器人 | 通过 AstrBot 启用/关闭选定平台连接；暂停后该连接不再接收新 QQ 消息 |
| 启用/停用插件 | 通过 AstrBot 加载/停用选定插件，状态由 AstrBot 保存；内置插件在此受保护 |
| 重载插件 | 重新加载选定插件，适合修改插件代码后使用 |
| 全部停止 | 停止服务；比“暂停机器人”更彻底，适合暂时不用机器人时使用 |

暂停连接或插件不能撤回已发送的消息。需要立即停止所有处理时使用“全部停止”。Nanami 的语音、戳一戳、存档等功能细项仍在网页插件配置中单独设置。

## 退出与后台进程

关闭控制台会停止它启动的服务，不会缩小到托盘继续运行。控制台为启动的服务建立 Windows 进程组，正常退出或控制台进程意外终止时，都由系统结束该组子进程。关机、重启后需要你再次手动打开控制台并启动服务。

以前通过其他启动器启动的服务会显示“外部启动”。停止或退出时会询问是否一起停止这些进程；拒绝会保留外部服务。控制台按本项目的安装路径和启动入口识别进程，不会批量结束其他 Python 或 QQ。未知程序占用端口时不会接管它。直接使用旧 `start.bat` 等脚本仍是独立启动方式，不受控制台退出保护，日常请统一从控制台启动。

## 密码与日志

- 控制台只连接 `127.0.0.1` 上的 AstrBot，不监听新的网络端口。
- 密码输入采用掩码；密码与管理令牌只在本次进程内使用，不保存到文件。
- 使用你目前的网页密码。`../AstrBot/local-access.txt` 只是初次部署的凭据记录，手动改密后不会自动更新，控制台不会替你重置密码。
- 服务输出在仓库外 `../work/control-panel/`，仅本机排错使用。日志可能包含运行数据，不要直接上传。
- 实际密钥、QQ 登录数据、聊天记录、音色模型仍留在仓库外，不随代码提交。

## 安装与目录

Windows、Python 3.12+，使用相邻 `../AstrBot/.venv`。现有环境已安装控制台依赖；新环境运行 `setup_astrbot.ps1` 会一并安装 `requirements-control-panel.txt`。此安装脚本也不会设置开机自启。

默认读取相邻的 `AstrBot`、`NapCat.44498.Shell`、`GPT-sovits/GPT-SoVITS-v2pro-20250604-nvidia50` 目录；NapCat 账号从既有 `napcat.quick.bat` 读取，不硬编码进控制台。自定义 AstrBot 位置时设置 `NANAMI_ASTRBOT_ROOT`。后端与窗口代码在 `control_panel/`，入口在 `scripts/control_panel.py`。

## 高 DPI 显示

控制台在创建窗口前启用 Windows 原生高 DPI 渲染，按所在显示器的 DPI 调整字体、间距、行高和窗口大小，避免系统放大整张窗口造成模糊。更新后关闭旧窗口并重新打开控制台生效；不需要更改 Windows 的显示缩放或 Python 的兼容性设置。如果移动到另一块缩放比例不同的显示器后尺寸不合适，可在该显示器上重新打开控制台。
